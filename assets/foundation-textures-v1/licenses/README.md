# Source and license ledger

This ledger is the provenance record for Foundation Texture Pack v1. It is a
practical summary, not legal advice. If an asset ever leaves this workspace as
a raw stock file rather than as part of a finished edit, re-check its current
source terms first.

## ambientCG — CC0 1.0

Official terms: <https://ambientcg.com/license>

ambientCG states that its assets are released under Creative Commons CC0 1.0.
They may be used commercially, modified, and redistributed without required
attribution.

the downloaded 2K source bundles. The unused 3D/PBR maps were deliberately not
added to the project.
